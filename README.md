
# 🎓 KL College - College Home Page

## 📌 Project Overview

This project is a simple and responsive college home page developed using HTML and CSS.

The website provides information about the college, courses, campus life, facilities, and contact details.

## 🚀 Features

- Responsive navigation bar
- Attractive college home banner
- Campus image collage
- About college section
- Courses information
- College facilities
- Contact details
- Responsive design for mobile and desktop
- Hover animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- Visual Studio Code

## 📂 Project Structure

college-homepage/
│
├── index.html
├── style.css
└── README.md

## ▶️ How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click on the HTML file.
5. Select **Open with Live Server**.
6. The college home page will open in your browser.

## 🖼️ Website Sections

### Home
Displays the welcome message and college banner.

### Campus Life
Displays a collage of college campus and student images.

### About
Provides information about the college.

### Courses
Displays available engineering courses:
- CSE
- ECE
- EEE
- MECH

### Facilities
Displays college facilities:
- Library
- Laboratories
- Sports

### Contact
Displays college contact information.
